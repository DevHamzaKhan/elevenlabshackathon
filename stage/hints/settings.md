# Settings (com.android.settings, Samsung One UI)

- Top: big title "Settings", then a search icon ("Search") and the Samsung account row. List of sections: "Connections", "Connected devices", "Modes and Routines", "Sounds and vibration", "Notifications", "Display", "Battery", "Wallpaper and style", "Themes", "Home screen", "Lock screen", "Security and privacy", "Location", "Safety and emergency", "Accounts and backup", "Google", "Advanced features", "Digital Wellbeing and parental controls", "Device care", "Apps", "General management", "Accessibility", "Software update", "About phone".
- **Fastest route**: tap "Search" (magnifier) → `type` the setting name (e.g. "dark mode", "Bluetooth") → tap the matching result.
- Toggles: a row's text is the setting name; the switch is often a separate node with the same text or desc "On"/"Off". Tap the switch, or the row (some rows open a sub-page instead).
- Common paths: Wi-Fi/Bluetooth/Airplane mode → "Connections". Dark mode → "Display" → "Dark". Brightness → "Display". Volume → "Sounds and vibration". Do not disturb → "Notifications" → "Do not disturb" (or Modes and Routines on newer One UI).

What goes wrong:
- Settings changes affect the real phone and can cut the hub connection. Never turn off Wi-Fi, mobile data, Bluetooth (earbuds!), accessibility services, or Bobby's notification access unless the user explicitly asked; confirm first for those.
- Long lists: swipe `up` to scroll. Section names differ between One UI versions; use Search if a name isn't visible.
- Quick Settings (pull-down panel, key `notifications`, then swipe `down` again) is faster for Wi-Fi, Bluetooth, Flashlight, Do not disturb; tiles show "Wi-Fi, On" style descriptions.
- Some pages ask for PIN/biometrics. Stop and tell the user; never guess.
