# Chrome (com.android.chrome)

- Address bar at the TOP by default (on some setups it's at the bottom): node with text "Search or type web address" (desc/resource "url_bar"), or the current URL when a page is open.
- Right of the address bar: "Switch or close tabs" (tab count), "Customize and control Google Chrome" (three dots menu). New Tab page shows a Google search box and shortcut tiles.
- **Search the web / open a site**: tap the address bar → `type` the query or URL → key `enter`.
- **Results**: Google results are a web view. Links usually expose their title text; tap the result title.
- Back: key `back` goes to the previous page. Menu → "New tab", "Bookmarks", "History".

What goes wrong:
- Web pages are web views: many buttons have no label, only nearby text. Prefer tapping visible link text; if nothing matches, ask for a fresh `screen` with an image or scroll.
- Cookie/consent banners ("Accept all", "Reject all", "I agree") cover content. Choose "Reject all" when available, else "Accept all" only if needed to continue.
- "Open in app?" or "Sign in to Chrome" prompts: tap "No thanks"/"Stay in Chrome"/"Use without an account".
- The address bar hides when scrolling down. Scroll up slightly (swipe `down`) to bring it back.
- The keyboard covers the lower half of forms; press `back` once to hide it (a second `back` leaves the page).
- Typing into a focused field the page owns may be refused; tap the field first.
